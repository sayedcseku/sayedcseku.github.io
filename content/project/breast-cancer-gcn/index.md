Built Graph Convolutional Neural Network models with Mask-RCNN backend to reason over bilateral and ipsilateral mammogram views for malignancy detection and semantic segmentation. Implemented architectural distortion augmentation to improve sensitivity to temporal and structural breast tissue changes over multiple visits.
